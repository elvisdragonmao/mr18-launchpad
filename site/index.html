MR18 Launchpad
操作 安裝 維護 GitHub

用 Launchpad Mini MK3
控制 MIDAS MR18

一支跑在 Raspberry Pi 上的 Python 程式。Launchpad 接 Pi 的 USB，Pi 透過網路用 OSC 控制 MR18。8×8 方格變成 8 條推桿，右側按鈕切換 Main 與 Aux 1–6，開機後自動啟動。

右邊這台可以按。試試看點方格調推桿、點右側按鈕換頁，或是用下面的開關模擬斷線。

下載 v1.0.0 安裝步驟

操作

推桿

每一欄是一條 8 段推桿，按哪一格推桿就設到哪裡。第 1 欄是 Master（Main LR，或目前選的 Aux Bus），亮黃色；第 2–8 欄是 7 個輸入聲道，亮綠色。

格1（上）2345678（下）
位置0 dB−5−10−20−30−45−60−∞

推桿在 −∞ 時只有最下面一格亮紅燈。最下面一格亮白燈表示還沒讀到 MR18 的數值。有人從 M-AIR Edit 改了推桿，Launchpad 幾秒內會跟著更新。

換頁與換聲道

右側按鈕
由上到下：Main、Aux 1 到 Aux 6、Settings。在 Aux 頁，第 2–8 欄調的是各聲道送到該 Aux 的量。目前的頁面亮紫色。
上方 ◀ ▶
切換第 2–8 欄對應的聲道：CH 1–7、CH 8–14、CH 15–16。還能往該方向切時，箭頭亮藍色。
Stereo Link
在 Main 頁，MR18 上有開 Channel Link 的兩個聲道，燈號會一起顯示。

Settings 頁

按最下面的 Stop / Solo / Mute 進入。只用到上面四排：

排功能燈號
1CH 1–8 Mute開啟　Mute
2CH 9–16 Mute開啟　Mute
3CH 1–8 輸入來源USB　Line
4CH 9–16 輸入來源USB　Line

右上角狀態燈

綠色代表 MR18 有回應。紅色代表超過 10 秒沒收到 MR18 回覆，這時程式不會送出任何改動，等網路恢復後重新讀取混音器的狀態。斷線前記住的推桿值不會被寫回去。

安裝

需要的東西

  • Raspberry Pi，Raspberry Pi OS 或其他用 systemd 的 Debian 系統
  • Novation Launchpad Mini MK3，USB 接在 Pi 上
  • MIDAS MR18，和 Pi 在同一個網路（OSC 用 UDP 10024 埠）

  1. 確認 Pi 連得到 MR18

    把 IP 換成你的 MR18。

    ping 10.3.255.251

  2. 下載

    wget https://github.com/elvisdragonmao/mr18-launchpad/releases/latest/download/mr18-launchpad.zip
unzip mr18-launchpad.zip -d ~/mr18-launchpad-src
cd ~/mr18-launchpad-src

    也可以用 git clone https://github.com/elvisdragonmao/mr18-launchpad.git。

  3. 執行安裝腳本

    用平常登入的使用者執行，不要加 sudo。如果之前有在終端機手動開著控制程式，先按 Ctrl+C 關掉，不然兩個程式會搶同一台 Launchpad。

    bash install_mr18_service.sh 10.3.255.251

    腳本會把程式放到 ~/mr18-launchpad/，在 ~/mr18-venv 準備 Python 環境（已經有就沿用），然後建立並啟動 mr18-launchpad 這個 systemd 服務。之後每次開機都會自動執行，不需要登入。

  4. 確認有在跑

    sudo systemctl status mr18-launchpad --no-pager
sudo journalctl -u mr18-launchpad -f

    日誌裡看到這兩行就是都接上了：

    [Launchpad 已連接] Input=Launchpad Mini MK3 ... MI 28:1; Output=...
[MR18 已連線 / 重新連線] ['10.3.255.251', 'MR18-82-ED-A9', 'MR18', '1.26']

裝好之後實測一次

開著 journalctl -f，依序試這三件事，確認燈號和控制都會回來：

  1. 拔掉 Launchpad 的 USB 再插回去。約 2 秒內會重新連上。
  2. 拔掉 MR18 的網路線，等 10 秒狀態燈變紅，再插回去。
  3. 重開 Raspberry Pi，不登入，直接按 Launchpad。

維護

斷線時會發生什麼

情況程式的處理
Launchpad USB 被拔掉程式繼續執行，每 2 秒找一次裝置
Launchpad 插回去重新開啟 MIDI Port、重畫燈號；Port 編號變了也認得
MR18 網路中斷10 秒沒回應就暫停寫入，狀態燈變紅
MR18 網路恢復重新讀取音量、Mute、輸入來源
Raspberry Pi 重開機systemd 自動啟動
程式意外結束systemd 約 3 秒後重新啟動

常用指令

sudo systemctl restart mr18-launchpad        # 重啟
sudo systemctl stop mr18-launchpad           # 暫時停止
sudo systemctl start mr18-launchpad          # 再次啟動
sudo systemctl disable --now mr18-launchpad  # 取消開機自動執行

手動測試

先停掉服務，再手動執行。不加 --arm 時按 Launchpad 只會印出要送的指令，不會改動 MR18。

sudo systemctl stop mr18-launchpad
~/mr18-venv/bin/python3 ~/mr18-launchpad/mr18_launchpad.py --host 10.3.255.251

確認沒問題再加上 --arm。測完按 Ctrl+C，然後 sudo systemctl start mr18-launchpad。

換 MR18 的 IP

用新 IP 重跑一次安裝腳本就好。
