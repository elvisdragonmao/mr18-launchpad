# 按鍵與燈號

程式啟動後會把 Launchpad 切到 Programmer Mode，停止時切回 Live Mode。

```
 ▲    ▼    ◀    ▶   Session Drums Keys User  [狀態]
┌────┬────┬────┬────┬────┬────┬────┬────┐
│ M  │ 1  │ 2  │ 3  │ 4  │ 5  │ 6  │ 7  │  > Main
│ M  │    │    │    │    │    │    │    │  > Aux 1
│ M  │    │    │    │    │    │    │    │  > Aux 2
│ M  │    │    │    │    │    │    │    │  > Aux 3
│ M  │    │    │    │    │    │    │    │  > Aux 4
│ M  │    │    │    │    │    │    │    │  > Aux 5
│ M  │    │    │    │    │    │    │    │  > Aux 6
│ M  │    │    │    │    │    │    │    │  Settings
└────┴────┴────┴────┴────┴────┴────┴────┘
 M = Master（Main LR 或目前的 Aux）
 1–7 = 目前 Bank 的輸入聲道
```

## 頁面（右側按鈕）

| 按鈕 | 頁面 | 第 1 條推桿 | 第 2–8 條推桿 |
| --- | --- | --- | --- |
| 第 1 顆 | Main | Main LR | 各聲道送到 Main 的推桿 |
| 第 2–7 顆 | Aux 1–6 | 該 Aux Bus 的 Master | 各聲道送到該 Aux 的 Send |
| 最下面 Stop/Solo/Mute | Settings | — | — |

目前所在的頁面按鈕亮紫色，其他亮暗綠色。

## Bank（上方 ◀ ▶）

| Bank | 第 2–8 條推桿 |
| --- | --- |
| 1 | CH 1–7 |
| 2 | CH 8–14 |
| 3 | CH 15–16（其餘五條不亮） |

還能往該方向切換時，箭頭亮藍色。▲ ▼ 與 Session / Drums / Keys / User 不使用。

## 推桿

每一欄是一條 8 段推桿，按某一格就把推桿設到那個位置：

| 格 | 位置 |
| --- | --- |
| 最上面 | 0 dB |
| 第 2 格 | −5 dB |
| 第 3 格 | −10 dB |
| 第 4 格 | −20 dB |
| 第 5 格 | −30 dB |
| 第 6 格 | −45 dB |
| 第 7 格 | −60 dB |
| 最下面 | −∞（推桿拉到底） |

燈號：

| 燈號 | 意思 |
| --- | --- |
| 黃色長條 | Master 推桿目前的位置 |
| 綠色長條 | 聲道推桿目前的位置 |
| 只有最下面一格亮紅 | 推桿在 −∞ |
| 只有最下面一格亮白 | 還沒讀到 MR18 的數值 |

推桿位置在兩格之間時，以最接近的一格顯示。高於 0 dB 的值顯示為滿格。

MR18 上的推桿被別人改動時（例如用 M-AIR Edit），Launchpad 約 4 秒內會跟著更新。

### Stereo Link

在 Main 頁，如果 MR18 的某組聲道開了 Channel Link，而且 Link 設定裡勾了 Fader / Mute / Sends，兩個聲道的燈號會一起顯示奇數聲道的數值。按其中一條只會送出一次寫入，由 MR18 自己同步另一個聲道。Aux 頁不做這個處理。

## Settings 頁

| 排 | 內容 | 燈號 |
| --- | --- | --- |
| 第 1 排 | CH 1–8 Mute | 綠 = 開啟，紅 = Mute |
| 第 2 排 | CH 9–16 Mute | 綠 = 開啟，紅 = Mute |
| 第 3 排 | CH 1–8 輸入來源 | 藍 = USB，黃 = Line |
| 第 4 排 | CH 9–16 輸入來源 | 藍 = USB，黃 = Line |
| 第 5–8 排 | 不使用 | — |

按一下切換。亮白色表示還沒讀到狀態，這時按下去只會先查詢，收到狀態後再按一次才會切換。

## 狀態燈（右上角 Logo 鍵）

| 燈號 | 意思 |
| --- | --- |
| 綠 | MR18 連線中，可以操作 |
| 紅 | MR18 沒有回應，暫停所有寫入 |
